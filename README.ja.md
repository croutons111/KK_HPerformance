# KK_HPerformance

[English](README.md) | **日本語**

> コイカツの **H の体位開始・体位変更で画面が止まる時間を短くし**、**キャラが多いときの FPS を上げる** BepInEx プラグインです。

---

## 概要

コイカツは H の体位を始めたり変えたりするたびに、多くのデータをディスクから読み直します。そのため、MOD を入れていない状態でも画面全体が一瞬止まります。また、キャラが多いと、髪・スカート・胸の揺れや、射精エフェクト「詳細」の精液で FPS が大きく下がります。

KK_HPerformance はその両方を軽くします。

- **止まる時間を短く** — H シーンの間、アニメや H の表をメモリに持っておきます。一度使った体位は、次からずっと速く始まります。
- **FPS を上げる**
  - FPS が下がったときに、髪・スカート・胸の揺れの計算が積み重なって、さらに重くなるのを防ぎます。
  - 画面に映っていないキャラは揺れを止めます。
  - 精液エフェクト「詳細」の作り直しを間引いて、早めに落ち着かせます。射精直後のカクつきも小さくなります。
- **計測（任意）** — どこが重いかをログに出す、調べもの用の機能です。

ゲーム本体の読み込みと揺れの処理に効くので、本体のキャラにも、他のプラグインが追加したキャラにも同じように効きます。H シーンの見た目や遊び方は変わりません。

## 導入方法

1. [Releases](../../releases) から最新の `KK_HPerformance.dll` をダウンロードします。
2. `BepInEx/plugins/` フォルダに入れます。
3. ゲームを起動します。

---

## 使い方

入れるだけで動きます。操作は要りません。

- **止まる時間の短縮** は H シーンで効きます。各体位の1回目はいつもどおり読み込み、2回目から速くなります。
- **揺れと FPS の改善** は、スタジオを含むすべてのシーンで効きます。揺れの計算の制限は、FPS が 60 を下回ったときだけ働きます。
- **精液エフェクトの改善** は、ゲームの設定で射精エフェクトを **「詳細」** にしているときに効きます。

元の動作に戻したいときは、Config の `General > Enabled` を OFF にします。すぐに反映されます。

## 設定

ゲーム中に ConfigurationManager（F1）から変更できます。

### General

| 項目 | 既定値 | 説明 |
|---|---|---|
| Enabled | ON | プラグイン全体の ON/OFF。OFF = 元のゲームの動作 |

### Cache（止まる時間の短縮）

| 項目 | 既定値 | 説明 |
|---|---|---|
| Animator Controllers | ON | 体位のアニメを毎回読み直さず、メモリに持っておく |
| Controller Cache Lifetime | HScene | `HScene` = H シーン終了で捨てる。`Session` = ゲームを閉じるまで持つ（次の H シーンでも1回目から速いが、メモリを多く使う） |
| List Texts | ON | H の表（反応・音・付属物など）をメモリに持っておく |
| Bundle Lookups | ON | どのデータファイルに何が入っているかを覚えておく |

### Performance（FPS）

| 項目 | 既定値 | 説明 |
|---|---|---|
| Dynamic Bone Max Steps | 1 | FPS が下がったとき、髪・スカート・胸の揺れが遅れを取り戻すために1フレームで計算する回数の上限（1〜3）。3 = 元のゲーム |
| Dynamic Bone Off-Screen Culling | ON | 画面に映っていないキャラ・非表示のキャラの揺れを止める |
| Culling Screen Margin (m) | 0.5 | 画面に映っているかを判定するときの、体のまわりの余白（長い髪やスカートのため） |
| Culling Max Distance (m) | 0 | カメラからこれより遠いキャラの揺れも止める。0 = 距離では止めない |
| Metaball Rebuild Interval | 2 | 精液エフェクト「詳細」を何フレームに1回作り直すか（1〜4）。1 = 元のゲーム |
| Metaball Settle Time | 6 | 精液のしずくがその場に止まるまでの秒数（2〜10）。10 = 元のゲーム |
| Metaball Cell Budget | 0 | 作り直しがとても大きくなる回だけ、精液の形を粗くする。0 = 制限なし |

### Debug

| 項目 | 既定値 | 説明 |
|---|---|---|
| Load Profiler | OFF | 読み込みにかかった時間と、止まったフレームの内訳をログに出す |
| Load Profiler Hitch Threshold (ms) | 100 | これより長いフレームを内訳つきで報告する |
| Load Profiler Min Log (ms) | 5 | これより短い読み込みは1件ずつのログを出さない |
| Frame Profiler | OFF | フレームのどこが重いか（ゲーム本体と各プラグイン）を、FPS とキャラ数と一緒にログに出す |
| Frame Profiler Report Interval (sec) | 5 | 集計をログに出す間隔 |
| Frame Profiler Top N | 20 | 1回の集計に載せる、重いものの数 |

プラグインを ON のまま元のゲームの動作に戻すときは、`Dynamic Bone Max Steps` = 3、`Dynamic Bone Off-Screen Culling` = OFF、`Metaball Rebuild Interval` = 1、`Metaball Settle Time` = 10 にします。

---

## 注意点

- **Debug** の計測は調べもの用です。ゲームの動作は変えませんが、計測そのもので少し FPS が下がります。終わったら OFF に戻してください。
- 揺れを止めていたキャラが画面に戻ると、髪やスカートを今の姿勢に合わせ直してから揺れを再開します。伸びたり跳ねたりはしません。
- `Controller Cache Lifetime = Session` にすると、遊んでいる間ずっとアニメを持ち続けるので、メモリを多く使います。
